Sobre mim

Sou Rodrigo Bragagnolo, um desenvolvedor full-stack apaixonado por tecnologia e resolução de problemas. Minha jornada começou no desenvolvimento front-end, onde aprimorei minhas habilidades na criação de interfaces intuitivas e responsivas usando frameworks modernos para web e mobile. Com o tempo, expandi meus conhecimentos para o desenvolvimento back-end, aprendendo tecnologias essenciais para construir aplicações robustas e escaláveis. Ao longo da minha experiência, trabalhei em projetos pessoais e acadêmicos, explorando constantemente novas ferramentas e boas práticas para aprimorar minhas habilidades. Estou sempre em busca de aprendizado, melhoria contínua e criação de soluções digitais inovadoras que gerem impacto.

Rede Social Orbee

Cópia Netflix

Neste projeto pessoal, desenvolvi uma réplica da interface do site da Netflix, focando exclusivamente no front-end. Utilize Angular e TypeScript para recriar a estrutura e o design visual da plataforma de streaming, incorporando efeitos visuais inspirados no layout da Netflix 2024.

Finans

Apresento o projeto de simulação de empresa financeira, desenvolvido com dedicação e expertise. Com um design elegante e recursos abrangentes, nossa plataforma oferece aos usuários a oportunidade de explorar diversos aspectos financeiros.

Seguradora TopCar - CRUD

Este projeto é uma simulação de uma empresa de seguros de automóveis, desenvolvido para fins educacionais e de demonstração. O usuário poderá criar um perfil, visualizar seus dados, editar informações e excluir sua conta (CRUD).

Clima & Tempo - API

Este projeto é um site que fornece aos usuários informações sobre o clima de qualquer localidade que escolherem. Basta pesquisar o lugar desejado, e pronto! Este software utiliza três APIs para fornecer informações precisas: OpenWeather API, TimeZone DB e FlagsAPI.

Gerenciador de Biblioteca - Java

Este projeto de Sistema de Gerenciamento de Biblioteca em Java permite a administração de livros, usuários e empréstimos. O principal objetivo é praticar conceitos básicos e intermediários de Java, como POO, manipulação de arquivos, estruturas de dados, entre outros. O sistema registra, atualiza e organiza os dados de forma simples, sem o uso de frameworks.
